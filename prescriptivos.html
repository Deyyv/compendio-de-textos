Textos Prescriptivos

Los textos prescriptivos son aquellos que indican acciones, recomendaciones o conductas que deben seguirse para actuar correctamente ante determinadas situaciones.

¿Qué son los textos prescriptivos?

Los textos prescriptivos son textos que buscan orientar las acciones o el comportamiento del lector mediante indicaciones, recomendaciones, obligaciones o prohibiciones. Su finalidad es señalar qué debe hacerse, qué se recomienda hacer o qué debe evitarse en una determinada situación.

Se pueden encontrar en recomendaciones de uso, protocolos de seguridad, instrucciones de comportamiento, indicaciones de salud, recetas y diferentes documentos relacionados con actividades profesionales.

Propósito

El propósito de los textos prescriptivos es orientar al lector para que realice determinadas acciones o adopte comportamientos adecuados. Esto permite prevenir errores, reducir riesgos y facilitar el cumplimiento de determinadas recomendaciones.

Características principales

  • Indican acciones: señalan qué debe hacerse ante una situación determinada.
  • Orientan el comportamiento: buscan que el lector actúe de una manera específica.
  • Utilizan lenguaje claro: las indicaciones deben ser fáciles de comprender.
  • Pueden expresar obligaciones o recomendaciones: algunas indicaciones son necesarias y otras funcionan como sugerencias para actuar correctamente.
  • Pueden incluir prohibiciones: señalan acciones que deben evitarse para prevenir problemas o riesgos.
  • Se relacionan con situaciones concretas: sus indicaciones están pensadas para determinadas actividades o circunstancias.

Diferencia entre textos instructivos y prescriptivos

Aunque ambos tipos de texto indican acciones, existe una diferencia en su finalidad.

Textos Instructivos Textos Prescriptivos
Explican cómo realizar una actividad mediante pasos ordenados. Indican qué acciones o comportamientos deben seguirse ante una situación.
Se enfocan principalmente en el procedimiento. Se enfocan principalmente en orientar o establecer una conducta.
Ejemplo: instalación de un programa. Ejemplo: recomendaciones de seguridad.

Ejemplo aplicado

A continuación se presenta un ejemplo de texto prescriptivo relacionado con el área de desarrollo de contenido digital y software.

Recomendaciones de seguridad para trabajar con computadoras

Objetivo: establecer recomendaciones para trabajar de manera segura y responsable con equipos de computación.

Recomendaciones

  1. Mantenga el área de trabajo limpia, ordenada y libre de líquidos.
  2. Utilice el equipo sobre una superficie estable y con suficiente ventilación.
  3. Evite tocar cables, conexiones eléctricas o componentes internos con las manos húmedas.
  4. Realice pausas periódicas durante períodos prolongados frente a la pantalla.
  5. Mantenga una postura adecuada para reducir molestias durante el trabajo.
  6. Evite descargar archivos o programas desde sitios web desconocidos.
  7. Utilice contraseñas seguras y evite compartirlas con otras personas.
  8. Realice copias de seguridad de los archivos importantes para prevenir la pérdida de información.
  9. No conecte dispositivos externos desconocidos al equipo sin verificar su seguridad.

Aplicación

Estas recomendaciones ayudan a reducir riesgos, proteger los equipos y mantener segura la información utilizada durante las actividades de desarrollo de software y contenido digital.

Importancia en el ámbito profesional

Los textos prescriptivos son importantes en el ámbito profesional porque permiten orientar las acciones de las personas y promover prácticas adecuadas durante el desarrollo de diferentes actividades.

En el área de tecnología y desarrollo de software, pueden utilizarse para establecer recomendaciones de seguridad, protección de información, uso responsable de equipos y buenas prácticas durante el trabajo.

Conocer este tipo de textos permite comprender mejor las indicaciones y recomendaciones que deben aplicarse en diferentes situaciones profesionales.
